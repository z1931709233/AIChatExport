# 腾讯元宝聊天导出工具使用说明

## 1. 文件说明

SVN 中只需要保存以下两个文件：

```text
chat-export.v2.user.js
腾讯元宝聊天导出工具-使用说明.md
```

`chat-export.v2.user.js` 是可直接安装到 Tampermonkey 的成品脚本，不需要同时上传项目源代码、测试文件或构建工具。

## 2. 运行条件

- Windows 10/11。
- 最新版 Google Chrome 或 Microsoft Edge。
- 浏览器已安装 Tampermonkey（篡改猴）扩展。
- 已在浏览器中正常登录腾讯元宝网页版。
- 使用地址：<https://yuanbao.tencent.com/>。
- “全部会话”导出依赖浏览器的文件夹写入功能，因此建议使用 Chrome 或 Edge。

## 3. 安装脚本

1. 打开 Tampermonkey 管理面板。
2. 选择“添加新脚本”。
3. 删除编辑器中的默认内容。
4. 打开 `chat-export.v2.user.js`，复制全部内容并粘贴到编辑器。
5. 保存脚本，并确认该脚本处于启用状态。
6. 关闭已经打开的腾讯元宝标签页，再重新打开元宝网页。
7. 页面加载完成后，右下角会出现聊天导出按钮。

更新版本时，请打开 Tampermonkey 中原来的脚本，用新版 `chat-export.v2.user.js` 全部覆盖并保存。更新后应关闭旧的元宝标签页再重新打开，避免旧版脚本仍留在页面中运行。

## 4. 导出当前会话

1. 在腾讯元宝中打开需要导出的具体对话，确认地址类似：

   ```text
   https://yuanbao.tencent.com/chat/<agentId>/<conversationId>
   ```

2. 点击页面右下角的导出按钮。
3. 选择“当前会话”。
4. 选择 JSON 或 Markdown 格式。
5. 点击“导出”。
6. 浏览器会按照当前下载设置保存文件。

当前会话导出始终以地址栏中的会话 ID 为准，不会随意选择缓存中的其他对话。

## 5. 导出全部会话

1. 登录腾讯元宝，并进入任意正常聊天页面。
2. 点击页面右下角的导出按钮。
3. 选择“全部会话”。
4. 点击“导出”。
5. 浏览器弹出目录选择窗口后，选择一个专门用于保存备份的总目录，例如：

   ```text
   D:\ChatHistory
   ```

6. 授权网页写入该目录。
7. 保持元宝标签页和浏览器打开，等待进度显示完成。

全部导出会自动处理：

- 当前/default agent 的普通历史会话；
- “分组”中的会话；
- 历史列表分页；
- 长对话详情分页；
- 重复消息去重；
- 请求节流、有限重试和失败后继续；
- 本地缓存和中断后的续传。

一个对话成功取得后会立即写入本地，不需要等所有对话下载完成后再统一打包。单个对话失败不会导致已经完成的文件丢失。

## 6. 导出目录结构

用户选择的目录就是总目录，不会再额外创建 ZIP 文件。每个会话会自动创建一个子目录：

```text
<会话ID>_<时间>_<分组名>
```

示例：

```text
D:\ChatHistory\
├─ 0PrhVazwYqW_20260830-092004_游戏设计\
│  ├─ raw.json
│  └─ conversation.md
├─ 0Q0bXeiRNzs_20260829-183512_其他\
│  ├─ raw.json
│  └─ conversation.md
└─ metadata.json
```

命名规则：

- 第一部分是完整会话 ID；
- 第二部分是会话时间，格式为 `年月日-时分秒`；
- 第三部分是元宝分组名称；
- 没有分组的会话使用“其他”；
- Windows 不允许的文件名字符会被自动替换；
- 名称重复时自动追加 `_2`、`_3`，不会覆盖本次导出的其他会话。

文件用途：

- `raw.json`：以元宝接口原始数据为主的完整备份，适合长期保存和以后重新处理；
- `conversation.md`：便于直接阅读的 Markdown 文档；
- `metadata.json`：本次导出的总清单、成功/失败数量、缓存使用情况和分组分页诊断信息。

## 7. 缓存与断点续传

脚本会将已经完整下载的会话保存在浏览器本地缓存中。如果浏览器关闭、页面刷新或导出中断，再次执行“全部会话”时，可以复用符合条件的缓存并继续处理剩余会话。

注意：

- 不要随意清除元宝网站数据、IndexedDB、Local Storage 或浏览器站点缓存，否则断点记录可能丢失。
- 即使使用缓存，导出时仍需重新获取服务器历史列表，以发现新会话、分组变化和更新时间变化。
- 若需要完全重新下载，可在清除该网站缓存后重新导出；清除前应确认已有文件已经妥善保存。

## 8. 使用期间注意事项

- 导出过程中不要关闭元宝标签页或退出浏览器。
- 可以打开开发者工具查看日志；如果 `F12` 无效，可右键页面选择“检查”，或按 `Ctrl+Shift+I`。
- 不要同时在多个元宝标签页启动全部导出，以免产生重复请求和目录写入冲突。
- 导出速度会故意受到限制，避免短时间大量请求腾讯接口。历史很多或单个对话很长时需要等待。
- 浏览器必须保持登录状态。登录失效、网络中断或腾讯接口变化都可能造成部分会话失败。
- 导出内容属于用户自己的聊天数据，请将目标目录放在安全位置，谨慎同步或分享。

## 9. 常见问题

### 9.1 页面没有显示导出按钮

确认 Tampermonkey 已启用脚本，然后关闭元宝标签页并重新打开。还可在 Tampermonkey 管理面板确认脚本匹配 `yuanbao.tencent.com`。

### 9.2 点击后提示 `Illegal invocation`

这通常表示浏览器中仍运行着旧版脚本。请用最新文件覆盖 Tampermonkey 脚本，保存后关闭原元宝标签页，再新开标签页测试。还应确认没有同时启用两个不同版本的 Chat Export Toolkit。

### 9.3 全部导出缺少部分记录

先查看总目录中的 `metadata.json`：

- `listedCount` 表示发现的会话总数；
- `exportedCount` 表示实际写入数量；
- `failures` 记录详情下载失败；
- `normalizationFailures` 记录文件转换或写入失败；
- `groupedConversationDiagnostics` 记录每个分组的发现数量和分页错误。

保留该文件，并将相关错误信息提供给维护者排查。

### 9.4 可以直接保存到任意 Windows 目录吗

可以，但必须在浏览器弹出的目录选择窗口中手动选择并授权。网页脚本不能绕过浏览器安全机制，直接写入一个未经用户选择的路径。

## 10. 代码来源、改编方式与许可证说明

本脚本由 **OpenAI Codex** 在本地仓库中协助检查、修改、测试和构建，改编基础是：

- 项目名称：`chat-export-toolkit`
- 上游仓库：<https://github.com/gandli/chat-export-toolkit>
- npm 包名：`chat-export-toolkit`
- 原项目许可证标注：MIT
- 本次改编基于仓库原有的 adapter、normalizer、store、interceptor 和 exporter 架构完成。

主要开发与构建工具包括：

- TypeScript
- Vite
- `vite-plugin-monkey`（生成 Tampermonkey Userscript）
- Vitest（自动测试）
- JSZip 3.10.1（项目原有 ZIP 能力的运行时依赖；当前“全部会话”默认直接写入目录）

腾讯元宝支持是根据元宝网页版当前公开可观察到的同源请求端点、请求字段、响应结构和分页行为，在 `chat-export-toolkit` 的 MIT 架构中独立实现的。脚本使用用户已经登录的元宝网页会话请求用户自己的数据。

本次实现没有把 **AfterChat — LLM Chat Exporter（AGPL-3.0）** 的源代码直接复制进该项目。接口名称和数据字段属于为兼容网页服务所必需的行为信息，不代表复制其程序实现。

如需对外分发或长期归档，建议同时保留原项目来源、版本信息及适用的 MIT 许可证声明，并自行确认腾讯元宝服务条款及数据使用要求。

## 11. 当前范围与限制

- “全部会话”当前指地址中所对应的当前/default agent，包括该 agent 下普通会话和分组会话。
- 暂未使用未经验证的接口猜测账号中的所有 agent，因此不能声称一次覆盖整个账号的所有 agent。
- 腾讯元宝是在线服务，其网页接口可能更新；接口变化后脚本可能需要同步维护。
- 自动测试使用模拟请求，不依赖真实腾讯账号；最终效果仍受真实账号权限、网络和腾讯服务状态影响。
