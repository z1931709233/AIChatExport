# 腾讯元宝聊天导出工具使用说明

## 安装与更新

1. 安装并打开 Tampermonkey。
2. 新建脚本，将 `chat-export.v2.user.js` 的全部内容粘贴进去并保存。
3. 登录 <https://yuanbao.tencent.com/>。
4. 更新脚本后，请关闭旧的元宝标签页重新打开或ctrl+F5强制刷新，避免旧代码继续运行。
5. 页面右下角出现“+”按钮后即可使用。

## 导出当前会话

打开具体对话，点击导出按钮，选择“当前会话”再点击“导出”，然后选择保存总目录。元宝的当前会话也会创建独立文件夹，同时写入 `raw.json`、`conversation.md`、`images/` 和 `files/`；面板中的格式选项不影响元宝目录备份。当前会话以地址中的 conversationId 为准。

## 导出全部会话

1. 点击导出按钮并选择“全部会话”。
2. 在浏览器窗口中选择一个总目录，例如 `D:\ChatHistory\元宝`。
3. 保持元宝页面和浏览器开启，等待进度完成。

脚本会获取当前/default agent 的普通历史和所有分组会话，自动处理历史分页、长对话分页、去重、有限重试、本地缓存和断点续传。单个会话或附件失败不会删除已经写入的结果。

## 目录结构

```text
D:\ChatHistory\元宝\
├─ <会话ID>_<时间>_<分组名>\
│  ├─ raw.json
│  ├─ conversation.md
│  ├─ images\
│  │  └─ 图片文件
│  └─ files\
│     └─ 代码及其他附件
└─ metadata.json
```

- 没有分组的会话使用“其他”。
- Windows 非法字符会自动替换。
- 重名会自动追加 `_2`、`_3`。
- `raw.json` 保存元宝接口原始信息；下载成功的图片或附件对象会增加 `localPath` 和 `localRelativePath` 字段，例如 `images/62a45c2223a04bb58954282fdae28e14_0.png`。
- `conversation.md` 保存便于阅读的内容，图片和附件链接会放在其对应消息内，不再统一追加到文件末尾。
- `images/` 保存图片。
- `files/` 保存 `.cs`、`.py`、`.json` 等代码文件及其他附件。
- `metadata.json` 保存总清单、缓存命中、失败记录和分组诊断。

图片和附件下载需要元宝登录状态。脚本会先通过元宝同源的 `/api/resource/v1/download` 将 resourceId 换成临时签名地址，再下载实际文件。若腾讯资源接口拒绝请求，脚本会继续导出文本，并在 `conversation.md` 的“未能下载的附件”和 `metadata.json` 的 `assetFailures` 中记录原因。

受浏览器文件系统安全机制限制，网页脚本无法读取用户所选目录的完整 Windows 绝对路径，因此 `raw.json` 记录的是相对于当前会话文件夹的可移植路径。将整个会话文件夹移动到其他电脑后，这些路径和 Markdown 链接仍然有效。

## 注意事项

- 不要同时在多个标签页启动全部导出。
- 导出期间不要关闭页面、退出登录或清除元宝站点数据。
- 历史较多时需要等待；脚本会主动节流，避免集中请求接口。
- 如果 `F12` 无效，可右键页面选择“检查”，或按 `Ctrl+Shift+I`。
- 导出的内容可能包含隐私、图片和源代码，请妥善保管。

## 代码来源与许可证

本脚本由 OpenAI Codex 基于 MIT 项目 [`gandli/chat-export-toolkit`](https://github.com/gandli/chat-export-toolkit) 的现有 adapter、normalizer、store、interceptor 和 exporter 架构改编，并使用 TypeScript、Vite、vite-plugin-monkey、Vitest 与 JSZip 等工具和依赖。

腾讯元宝功能依据网页当前可观察到的同源接口、字段和分页行为独立实现，没有直接复制 AfterChat — LLM Chat Exporter（AGPL-3.0）的源代码。对外分发时应保留原项目来源和适用的 MIT 许可证声明，并自行确认腾讯元宝服务条款及数据使用要求。

## 当前限制

- “全部会话”范围是当前/default agent，包括其普通会话和分组会话；尚不声称覆盖账号中的所有 agent。
- 腾讯元宝网页接口可能更新，接口变化后脚本可能需要同步维护。
- 浏览器跨域策略或资源权限可能导致个别附件无法下载，失败信息会写入导出结果。
